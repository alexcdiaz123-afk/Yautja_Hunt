[01] CAÑÓN DE PLASMA KALI: NMAP
OBJETIVO: SKULL 01 // RECONOCIMIENTO

Escaneo electromagnético perimetral de frecuencias y puertos TCP abiertos en la presa. Optimizado con -Pn para evitar demoras por ping en entornos virtuales.

nmap -Pn -p 1987,8080 <IP_PRESA>
KALI DOCS ↗

GUÍA RÁPIDA DE NMAP (PARA MÁQUINAS VIRTUALES):

  • -Pn: Trata el host como encendido. Evita que Nmap se quede colgado si la red de la VM no responde al ping ICMP.
  • -p 1987,8080: Escaneo directo a los puertos del laboratorio (tarda 1 segundo en lugar de 15 minutos).
  • Barrido de puertos altos: nmap -Pn -p 1000-2500 -T4 <IP> si buscas la baliza sin saturar la VM.
  • Evitar: No uses -p- -sV a ciegas en una VM con pocos recursos, pues saturará los sockets.
[02] CUCHILLAS DE MUÑECA KALI: NETCAT (NC)
OBJETIVO: SKULL 01 // BALIZA RADAR

Conexión directa cuerpo a cuerpo contra sockets TCP crudos. Intercepta la transmisión de la baliza de radar militar OWLF en tiempo real.

nc -vn <IP_PRESA> 1987
KALI DOCS ↗

GUÍA RÁPIDA DE NETCAT (NC):

  • -v (Verbose): Muestra si la conexión fue exitosa o rechazada.
  • -n (Numeric): Evita resolución DNS inversa, conectando de forma instantánea.
  • Uso: Al conectar a <IP> 1987, el servicio te responderá directamente con el banner del radar militar y el primer cráneo.
[03] ZOOM ESPECTRAL KALI: CURL / WHATWEB
OBJETIVO: SKULL 02 & SKULL 12/13

Inspección de metadatos invisibles en cabeceras HTTP (Banner Grabbing) y consumo de microservicios REST internos con parámetros de token.

curl -I http://<IP_PRESA>:8080/
KALI DOCS ↗

GUÍA RÁPIDA DE CURL:

  • -I (Head): Solo solicita las cabeceras HTTP de respuesta sin descargar el HTML.
  • -s (Silent): Oculta la barra de progreso para lecturas limpias en terminal.
  • Revisión clave: Busca cabeceras con prefijo X-Specimen-Traces o firmas militares de servidor.
[04] LANZADOR DE RED KALI: GOBUSTER / DIRB
OBJETIVO: SKULL 03 & SKULL 04

Fuzzing ágil para descubrir rutas denegadas y copias de seguridad (.env, .bak). Usa listas de palabras ligeras para no colgar la VM.

gobuster dir -u http://<IP>:8080/ -w /usr/share/wordlists/dirb/common.txt -t 20
KALI DOCS ↗

GUÍA RÁPIDA DE GOBUSTER:

  • -w common.txt: Usa diccionarios compactos (~4.000 palabras). Terminará en 10 segundos en tu VM.
  • -t 20 (Threads): Limita los hilos para no agotar la CPU ni la memoria de la máquina virtual.
  • Tip esencial: Revisa siempre primero http://<IP>:8080/robots.txt; a menudo revela las rutas ocultas sin necesidad de fuzzer.
[05] LANZA COMBISTICK KALI: BURP SUITE
OBJETIVO: SKULL 05 & SKULL 07

Manipulación precisa de peticiones web y delimitadores de sistema operativo (Command Injection en utilidad de diagnóstico térmico).

127.0.0.1; cat secret_access/flag07.txt
KALI DOCS ↗

GUÍA RÁPIDA DE COMMAND INJECTION:

  • Delimitador ';': Permite encadenar un segundo comando independiente en bash.
  • Delimitador '&&': Ejecuta el segundo comando si el primero tiene éxito. Vital si caes en modo Berserker (donde ';' está bloqueado).
  • Campo vulnerable: En /diagnostic, ingresa la IP seguida de ; cat secret_access/flag07.txt.
[06] DISCO INTELIGENTE KALI: SQL INJECTION
OBJETIVO: SKULL 06 // INYECCIÓN SQL

Proyectil guiado contra bases de datos relacionales SQLite. Permite extraer registros clasificados mediante inyecciones booleanas manuales en segundos.

' OR 1=1 --
KALI DOCS ↗

GUÍA RÁPIDA DE INYECCIÓN SQL:

  • Comilla simple ( ' ): Cierra la cadena del programador en la cláusula WHERE.
  • OR 1=1: Condición siempre verdadera que obliga a devolver todas las filas de la tabla.
  • Guión guión ( -- ): Comenta el resto de la consulta original de SQLite.
  • Inyección manual rápida: Pega ' OR 1=1 -- en el buscador de /specimens y presiona Enter; verás el espécimen secreto de inmediato.
