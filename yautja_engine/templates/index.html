[01] CAÑÓN DE PLASMA KALI: NMAP
VECTOR: RECONOCIMIENTO & AUDITORÍA DE PUERTOS

Escaneo electromagnético perimetral de frecuencias y puertos TCP abiertos en la presa. Descubre qué servicios militares están escuchando en la red del objetivo.

nmap -Pn [flags] -p [puerto(s)] <IP_OBJETIVO>
KALI DOCS ↗

GUÍA METODOLÓGICA DE NMAP (PARA ENTORNOS VIRTUALES):

  • -Pn: Trata al objetivo como encendido omitiendo la comprobación de ping ICMP. Indispensable en máquinas virtuales donde los adaptadores de red o firewalls descartan paquetes ICMP.
  • -p [puertos]: Escanea puertos específicos (ej: -p 80,8080 o rangos -p 1000-2500). Acotar los puertos toma menos de 2 segundos en lugar de minutos.
  • -T4: Perfil de temporización agresivo pero estable, ideal para redes internas o laboratorios Host-Only.
  • Recomendación para VM: Evita nmap -p- -sV indiscriminado, ya que puede saturar los descriptores de sockets en máquinas virtuales con pocos recursos.
[02] CUCHILLAS DE MUÑECA KALI: NETCAT (NC)
VECTOR: CONEXIONES CRUDAS & BANNER GRABBING

Conexión directa cuerpo a cuerpo contra sockets TCP crudos. Lee transmisiones continuas de texto emitidas por balizas o daemons de telemetría.

nc -vn <IP_OBJETIVO> <PUERTO_TCP>
KALI DOCS ↗

GUÍA METODOLÓGICA DE NETCAT (NC):

  • -v (Verbose): Proporciona retroalimentación inmediata indicando si la conexión TCP fue exitosa o si el puerto está cerrado/filtrado.
  • -n (Numeric): Desactiva la resolución de nombres DNS. Conecta directamente por dirección IP en milisegundos sin demoras por timeouts de red.
  • Interacción con Sockets: Al enlazar con un servicio que emite un banner interactivo o una baliza continua, Netcat volcará la información directamente en tu terminal.
[03] ZOOM ESPECTRAL KALI: CURL / WHATWEB
VECTOR: ANÁLISIS DE CABECERAS HTTP & APIS

Inspección espectral de metadatos invisibles en cabeceras HTTP de respuesta y consulta estructurada de microservicios web.

curl -I http://<IP_OBJETIVO>:<PUERTO>/[ruta]
KALI DOCS ↗

GUÍA METODOLÓGICA DE INSPECCIÓN HTTP:

  • -I (Head): Envía una petición HEAD para obtener exclusivamente los encabezados HTTP sin descargar el cuerpo HTML de la página.
  • Cabeceras personalizadas: Los desarrolladores y sistemas militares suelen incluir cabeceras de depuración (con prefijos como X-) o firmas de versiones.
  • -s (Silent): Oculta la barra de progreso de cURL para canalizar la respuesta limpiamente en scripts o pipes.
[04] LANZADOR DE RED KALI: GOBUSTER / FUZZING
VECTOR: ENUMERACIÓN DE RUTAS Y RECURSOS OCULTOS

Fuzzing controlado de directorios y archivos web para descubrir paneles administrativos, respaldos (.bak, .env) o zonas restringidas.

gobuster dir -u http://<IP_OBJETIVO>:<PUERTO>/ -w <DICCIONARIO> [flags]
KALI DOCS ↗

GUÍA METODOLÓGICA DE FUZZING WEB:

  • -w [diccionario]: Ruta al archivo de palabras en Kali (ej: /usr/share/wordlists/dirb/common.txt). Usa listas compactas para entornos virtuales.
  • -t [hilos]: Limita el número de hilos simultáneos (ej: -t 20) para evitar saturar el CPU o la memoria de tu máquina virtual.
  • Enumeración pasiva previa: Antes de recurrir a fuerza bruta, revisa siempre recursos estándar como /robots.txt o los comentarios en el código fuente HTML.
[05] LANZA COMBISTICK KALI: INYECCIÓN DE COMANDOS
VECTOR: RUPTURA DE ENTRADAS & COMMAND INJECTION

Penetración en utilidades del sistema que concatenan entradas del usuario directamente en la consola del servidor (OS Command Injection).

<ENTRADA_VÁLIDA> [DELIMITADOR] [COMANDO_SECUNDARIO]
KALI DOCS ↗

GUÍA METODOLÓGICA DE INYECCIÓN DE COMANDOS:

  • Delimitador ';': Permite ejecutar un segundo comando de forma secuencial e independiente en entornos Unix/Linux.
  • Delimitador '&&': Ejecuta el segundo comando únicamente si el comando anterior finaliza exitosamente (código de salida 0).
  • Evasión de filtros: Cuando una aplicación web bloquea ciertos caracteres especiales (como ;), probar delimitadores alternativos (&&, |, saltos de línea) permite sobrepasar los filtros.
  • Lectura de archivos: Utilidades estándar de terminal como cat o less permiten volcar el contenido de ficheros confidenciales del servidor.
[06] DISCO INTELIGENTE KALI: SQL INJECTION
VECTOR: MANIPULACIÓN DE CONSULTAS RELACIONALES

Proyectil guiado contra bases de datos relacionales SQLite. Altera la lógica interna de la consulta para eludir restricciones y exponer registros confidenciales.

' [OPERADOR_LÓGICO] [CONDICIÓN_VERDADERA] [COMENTARIO]
KALI DOCS ↗

GUÍA METODOLÓGICA DE INYECCIÓN SQL:

  • Comilla simple ('): Cierra la cadena de texto esperada por la consulta SQL subyacente.
  • Condición Tautológica (OR 1=1): Inyecta una condición que siempre se evalúa como verdadera, haciendo que la cláusula WHERE devuelva todos los registros.
  • Delimitador de Comentario (--): En motores como SQLite y PostgreSQL, dos guiones descartan el resto de la consulta original evitando errores sintácticos.
  • Identificación de vulnerabilidades: Probar caracteres delimitadores en cajas de búsqueda permite deducir si la entrada se concatena directamente en la base de datos.
[07] SECUENCIA DE MUÑECA KALI: GTFOBINS / SUID
VECTOR: ESCALADA VERTICAL DE PRIVILEGIOS LINUX

Auditoría interna del sistema operativo objetivo en busca de binarios SUID, tareas programadas desatendidas (cron) y archivos con permisos débiles.

find <RUTA> -perm <MÁSCARA> -type f 2>/dev/null
GTFOBINS ↗

GUÍA METODOLÓGICA DE ENUMERACIÓN LINUX / SUID:

  • -perm -4000: Busca binarios que posean el bit SUID (Set User ID) activado, ejecutándose con los privilegios del propietario (habitualmente root).
  • 2>/dev/null: Redirige los mensajes de error (como 'Permission denied') al dispositivo nulo para no ensuciar la salida en terminal.
  • Auditoría de Cron y Scripts: Revisa tareas automáticas y scripts auxiliares en el sistema; si un script con permisos de ejecución es ejecutado periódicamente por root, puede ser auditado para escalar privilegios.
[08] CAMUFLAJE ÓPTICO KALI: APIS INTERNAS / CURL
VECTOR: CONSUMO DE MICROSERVICIOS RESTRINGIDOS

Interacción con endpoints REST internos no documentados. Consumo de parámetros de autorización y encadenamiento de solicitudes para desactivar defensas.

curl -s http://<IP_OBJETIVO>:<PUERTO>/<ENDPOINT>?[PARAMETROS]
KALI DOCS ↗

GUÍA METODOLÓGICA DE APIS INTERNAS:

  • Descubrimiento de Endpoints: Los archivos de configuración o el código fuente a menudo revelan rutas API internas destinadas a telemetría o mantenimiento.
  • Autenticación basada en Tokens: Muchos endpoints validan un parámetro de consulta (ej: ?token=...) antes de ejecutar operaciones críticas.
  • Encadenamiento de Acciones: Los retos avanzados requieren recopilar información en fases previas (como tokens o códigos de purga) para enviarlos como parámetros en endpoints protegidos.
